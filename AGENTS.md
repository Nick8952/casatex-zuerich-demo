# Casatex Zürich Demo: Anweisungen für Agenten

Die verbindlichen Regeln, die Architektur und die Befehle dieses Projekts stehen in `CLAUDE.md` im selben Ordner. Sie gelten für
Claude und Codex gleichermassen. Zusätzlich gelten `../AGENTS.md` und `../CLAUDE.md` (Workspace, Obsidian-Brain).

Das Wichtigste in Kürze:

- Nichts über die Casatex Zürich AG erfinden. Jede Unternehmensaussage braucht eine Quelle (`herkunft`); Verzeichnisse zählen nicht.
- Nicht mit der Casatex GmbH in Untereggen (casatex.com) verwechseln.
- Die Website ist immer ein statischer Export. Keine Serverfunktionen, keine Dienste Dritter, keine Geheimnisse im Repository.
- Keine Sanity- oder Vercel-Projekte, Tokens oder Zugänge anlegen oder anfordern.
- Keine Nachrichten an das Unternehmen senden; das Formular nur mit fiktiven Daten testen.
- Vor jedem Commit: `npm run pruefen && npm run build && npm run export:pruefen`.
- Reviews durch Codex nur lesend (`--sandbox read-only`) und ohne Rückdelegation.
